# 🧠 MisconceptionHunter

### AI-Powered Agentic Learning System for Detecting Student Misconceptions

MisconceptionHunter is an AI-powered Agentic AI system that analyzes a student's answer, identifies the underlying misconception, verifies the reasoning, and generates a personalized learning challenge.

Instead of simply marking an answer as "wrong", MisconceptionHunter focuses on **WHY the student is wrong** and helps them correct their conceptual understanding.

---

## 🚨 Problem Statement

Traditional learning systems usually evaluate answers as:

✅ Correct  
❌ Incorrect

But a wrong answer does not always mean the student lacks knowledge.

A student may have a specific **misconception** about a concept.

For example:

> A student believes that an object keeps moving because a force continues to act on it.

Simply showing the correct answer does not necessarily remove this misconception.

MisconceptionHunter attempts to identify the reasoning behind the student's answer and provide targeted learning support.
